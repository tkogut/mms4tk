# Archiwum planów operacyjnych

Zarchiwizowane 2026-09-12 w ramach porządkowania dokumentacji. Wszystkie pliki
tutaj to plany **już dostarczone/wdrożone** — status na nagłówku każdego pliku
("Status: COMPLETE", "GOTOWY DO ZATWIERDZENIA" itd.) jest z dnia autoryzacji
planu i **nie był aktualizowany po wdrożeniu** — to nie jest błąd tych plików,
tylko powód, dla którego trafiły tu zbiorczo zamiast być poprawiane pojedynczo.

Rzeczywisty, zweryfikowany status dostarczenia każdego z nich: `.agents/MEMORY.md`
(sekcja "HISTORY OF DELIVERED PLANS") i `CHANGELOG.md` (wpis per wersja).

Jedyny plik pozostawiony aktywny poza tym archiwum: `.agents/plans/000-TEMPLATE.md`
(szablon do tworzenia nowych planów, nie plan sam w sobie).

Nic tu nie jest usunięte z historii Git — to tylko reorganizacja katalogu.
